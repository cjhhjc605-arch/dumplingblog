# JS 第二课：错误类型、运算符、条件语句与逻辑运算

  

> 本课对应练习文件：`index.html`（JS 错误类型）、`index1.html`（运算符与流程控制）。

  

# 一、JS 中的错误类型

  

JavaScript 中的错误大致分为两类：

  

## 1. 语法错误（Syntax Error）—— 中断执行

  

语法问题会导致**整个脚本块中断执行**，出错行之后的代码不会再运行。

  

```js

// 语法问题：中断执行

// console.log(1);

// console.log(2);

// console.log(a);

console.log(3)； // ← 这里用的是中文全角分号「；」，属于语法错误

// console.log(4); // 出错后，这行也不会执行

```

  

> 注意：中文标点（如全角分号 `；`、全角括号 `（）`、全角引号 `“”`）在代码里是不合法的，是初学者最常见的语法错误来源。

  

## 2. 通用错误（引用错误 Reference Error）

  

引用了**未定义的变量**等，属于通用错误（运行时错误）。

  

```js

// console.log(a); // a 未定义，抛出 ReferenceError

console.log(2); // 不受影响的代码仍可执行

```

  

## 3. 不同 `<script>` 块相互独立

  

每个 `<script>` 标签是一个独立的执行单元，**一个脚本块里的错误不会影响另一个脚本块**。

  

```html

<script>

console.log(3)； // 语法错误，中断当前脚本块

console.log(4); // 不执行

</script>

  

<script>

console.log(2); // 仍然正常执行

</script>

```

  

# 二、运算符（Operator）

  

## 1. 算术运算符：`+` `-` `*` `/` `%` `()`

  

```js

// + - * / % ()

var a = 1,

b = 2,

d = 3;

var c = (a + b) * d; // (1 + 2) * 3 = 9

```

  

**执行顺序（优先级）**：`括号运算 > 普通运算（乘除、加减）> 赋值`。

  

一条赋值语句其实包含三步：

1. 声明变量；

2. 计算（如 `a` 与 `b` 相加，再与 `d` 相乘）；

3. 把结果赋值给变量 `c`。

  

## 2. `+` 号的两个作用

  

`+` 既能做**数学加法**，也能做**字符串拼接**。

  

**规则：任何数据类型的值与字符串相加，结果都是字符串（拼接）。**

  

```js

var c;

c = 1 + "str"; // "1str"

c = "ste" + "str"; // "stestr"

c = "str" + undefined; // "strundefined"

c = "str" + true; // "strtrue"

c = "str" + NaN; // "strNaN"

  

// 拼接从左到右依次进行

c = "str" + 1 + 1; // "str11" （先 "str"+1 → "str1"，再 +1 → "str11"）

c = "str" + (1 + 1); // "str2" （括号先算 1+1=2，再拼接）

```

  

## 3. `/` 除法与特殊值：`NaN`、`Infinity`

  

### NaN —— Not a Number（非数）

  

`NaN` 表示「不是数字」，但它**属于 `number`（数字）类型**。

  

```js

var c;

c = 0 / 0; // NaN

c = "a" / "b"; // NaN

c = 1 / NaN; // NaN

```

  

### Infinity / -Infinity —— 无穷

  

```js

c = 1 / 0; // Infinity（正无穷）

c = -1 / 0; // -Infinity（负无穷）

```

  

## 4. `%` 取余（取模）

  

`%` 得到两数相除的**余数**。

  

```js

console.log(4 % 6); // 4 （4 除以 6 商 0 余 4）

console.log(5 % 2); // 1

```

  

## 5. 交换两个变量的值

  

### 方法一：借助临时变量

  

```js

var a = 1,

b = 2;

var c = a; // 临时保存 a 的值

a = b; // a 拿到 b 的值

b = c; // b 拿到原来的 a 的值

console.log(a, b); // 2 1

```

  

### 方法二：加减法（不借助第三个变量）

  

```js

var a = 1,

b = 2;

a = a + b; // a = 1 + 2 = 3

b = a - b; // b = 3 - 2 = 1

a = a - b; // a = 3 - 1 = 2

console.log(a, b); // 2 1

```

  

## 6. 自增 / 自减：`++` `--`

  

- `a++` 等价于 `a = a + 1`；`a--` 等价于 `a = a - 1`。

- **前置（`++a`）**：先自增，再返回**新值**；

- **后置（`a++`）**：先返回**旧值**，再自增。

  

```js

var a = 1;

console.log(a++); // 1 （先返回旧值 1，然后 a 变成 2）

  

var c = 1;

console.log(++c); // 2 （先自增为 2，再返回 2）

```

  

### 组合运算示例（设 `a = 5`）

  

| 表达式 | 计算过程 | 结果 (b, a) |

| -------------- | ------------------------------- | ----------- |

| `b = a++ + 1` | a++ 返回 5，b = 5+1，a 变 6 | 6, 6 |

| `b = ++a + 1` | ++a 先变 6，b = 6+1 | 7, 6 |

| `b = a-- + --a`| a-- 返回 5（a=4），--a 变 3 返回 3，b = 5+3 | 8, 3 |

| `b = --a + a--`| --a 变 4 返回 4，a-- 返回 4（a=3），b = 4+4 | 8, 3 |

| `b = --a + --a`| 第一次 --a 变 4 返回 4，第二次 --a 变 3 返回 3，b = 4+3 | 7, 3 |

| `b = --a + a++`| --a 变 4 返回 4，a++ 返回 4（a=5），b = 4+4 | 8, 5 |

  

# 三、比较运算符

  

比较运算符包括：`>` `<` `>=` `<=` `==` `!=` `===` `!==`。比较的结果是一个**布尔值**（`true` / `false`）。

  

## 1. number 与 number 比较

  

```js

var bool = 1 > 2; // false

```

  

## 2. number 与 string 比较（string → number）

  

```js

var bool = 1 > "2"; // false （"2" 先转成数字 2）

```

  

## 3. string 与 string 比较（按 ASCII 码逐个比较）

  

字符串比较时，会按**字符对应的 ASCII 码（字符的十进制代码）**从左到右逐个字符比较，直到比出大小为止。

  

```js

var bool = "4.5" > "11"; // true （第 1 位：'4'(52) > '1'(49)）

var bool = "1.5" > "11"; // false （第 1 位相等，第 2 位：'.'(46) < '1'(49)）

var bool = 'a' > 'b'; // false （'a'(97) < 'b'(98)）

```

  

## 4. `==` 与 `===` 的区别

  

| 运算符 | 含义 | 是否比较数据类型 |

| ------ | -------- | ---------------- |

| `==` | 相等 | 不看（会发生隐式转换） |

| `===` | 全等 | 看（类型和值都相等才为 true） |

  

```js

var bool = 1 !== "1"; // true （1 和 "1" 类型不同，不全等）

```

  

## 5. NaN 的特殊性

  

**`NaN` 与包括它自己在内的任何值都不相等。**

  

```js

var bool = NaN == NaN; // false

```

  

# 四、条件语句 if / else if / else

  

## 1. 基本语法

  

```js

if (条件) {

// 条件为真时执行

} else if (条件2) {

// 条件2 为真时执行

} else {

// 以上都不满足时执行

}

```

  

## 2. 示例：查询成绩等级

  

```js

var score = 73;

if (score >= 90 && score <= 100) {

console.log('您的成绩等级为A');

} else if (score >= 80 && score < 90) {

console.log('您的成绩等级为B');

} else if (score >= 70 && score < 80) {

console.log('您的成绩等级为C');

} else if (score >= 60 && score < 70) {

console.log('您的成绩等级为D');

} else if (score < 60 && score >= 0) {

console.log('您的成绩等级为不合格');

} else {

console.log('您的成绩出现异常');

}

```

  

> 要点：多个条件分支要注意**互斥性**（各个条件区间不能重叠、不能漏掉边界）。

> - `&&` 表示「并且」，两边条件**都**要满足；

> - `||` 表示「或者」，两边条件**任意一边**满足即可。

  

# 五、switch 语句

  

## 1. 基本语法

  

```js

switch (变量) {

case 值1:

语句;

break;

case 值2:

语句;

break;

default:

语句; // 都不匹配时执行

}

```

  

## 2. 示例：按城市查询薪资

  

```js

var city = window.prompt('请输入您所在的地区');

switch (city) {

case '北京':

console.log('15K');

break;

case '上海':

console.log('13K');

break;

case '广州':

console.log('10K');

break;

default:

console.log('9K');

break;

}

```

  

> **选择规则：有范围用 `if`，固定值用 `switch`。**

  

## 3. 嵌套 switch 示例

  

```js

var week = window.prompt('请输入星期几');

var time;

switch (week) {

case '星期一':

time = window.prompt('请输入早上中午晚上');

switch (time) {

case '早上':

document.write('今天是星期一早上：记单词');

break;

case '中午':

document.write('今天是星期一中午：吃烤肉');

break;

case '晚上':

document.write('今天是星期一晚上：看电影');

break;

}

break;

// …星期二到星期日同理…

default:

document.write('输入异常');

}

```

  

# 六、逻辑运算符 `&&` `||` `!`

  

## 1. 真假值（Truthy / Falsy）

  

**以下 6 个值一定是「假」：`undefined`、`null`、`NaN`、`""`（空字符串）、`0`、`false`。**

除上述之外的值**全是真**。

  

## 2. `&&`（与）

  

**规则：遇到「假」就停，返回当前值；一路都是「真」就走到最后，返回最后一个值。**

  

```js

var a = 1 && 2 && 4 && 10; // 10 （全真，返回最后一个）

var a = 1 && 2 && NaN && 33; // NaN （遇到 NaN 假，返回 NaN）

```

  

| 表达式 | 结果 |

| --------- | ----- |

| `1 && 1` | 1（真） |

| `0 && 1` | 0（假） |

| `1 && 0` | 0（假） |

| `0 && 0` | 0（假） |

  

## 3. `||`（或）

  

**规则：遇到「真」就停，返回当前值；一路都是「假」就走到最后，返回最后一个值。**

  

```js

var b = 1 || 2; // 1

var b = 0 || null || 1 || 0; // 1

```

  

| 表达式 | 结果 |

| --------- | ----- |

| `1 \|\| 1` | 1（真） |

| `0 \|\| 1` | 1（真） |

| `1 \|\| 0` | 1（真） |

| `0 \|\| 0` | 0（假） |

  

## 4. `!`（非）取反

  

`!` 把值取反（真变假、假变真）；`!!` 可以把任意值**转换成布尔值**。

  

```js

var a = !!1; // true （!!1 = !false = true）

var a = !a; // 对 a 取反

// a = !a 相当于 a 变成与原来相反的真假值

console.log(a); // false

```

  

# 本课小结

  

- **语法错误**会中断当前脚本块执行，**通用错误**（如引用未定义变量）不会影响其他脚本块；

- 运算符优先级：**括号 > 乘除/加减 > 赋值**；

- `+` 有「加法」和「字符串拼接」两个作用，任何值与字符串相加都变成字符串；

- `NaN` 是数字类型、与任何值（含自己）都不相等；`1/0` 得 `Infinity`；

- `++`/`--` 分前置与后置，注意返回旧值还是新值；

- 字符串比较按 **ASCII 码**逐个字符进行；

- `==` 不看类型、`===` 看类型（推荐用 `===`）；

- 有范围用 `if`，固定值用 `switch`；

- `&&` 遇假停、`||` 遇真停；`undefined / null / NaN / "" / 0 / false` 是假值。
