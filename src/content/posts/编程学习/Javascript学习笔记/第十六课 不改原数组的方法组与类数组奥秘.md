# JS 第十六课：不改原数组的方法组与类数组奥秘

  

> 本课对应练习文件：`index.html`（不改原数组的方法组 concat / toString / slice / join / split 精讲、slice 与 splice 全维度对比、join 与 split 互逆操作、类数组对象三要素、arguments 探秘、借用数组方法的经典 obj.push 覆盖题）。

  

# 一、两大阵营：改原数组 vs 不改原数组

  

![数组方法两大阵营：改原数组 vs 不改原数组](https://img.215454.xyz/file/blog/jia/1792058488957_01-immutable-vs-mutable.png)

  

上节课的"七兄弟"（`push` / `unshift` / `pop` / `shift` / `reverse` / `splice` / `sort`）全部**原地修改**原数组；这节课认识的新朋友（`concat` / `toString` / `slice` / `join` / `split`）则完全不同——**只根据原数组算出一个新结果，原数组一个元素都不动**。

  

> **学习新方法的"三问法"：** ① 改不改原数组？（先打印前后对比验证）② 返回值是什么？（新数组 / 字符串）③ 参数怎么传？（区间？分隔符？）——任何新方法都靠这三问拆解，比背代码管用一百倍。

>

> 小提醒：`split` 其实是**字符串的方法**（挂在 `String.prototype` 上），但它和 `join` 是一对互逆操作，所以放在一起学。

  

# 二、concat：拼接，不改家

  

![concat 与 toString：拼接生成新数组、逗号连成字符串](https://img.215454.xyz/file/blog/jia/1792058496481_02-concat-toString.png)

  

```js

var arr1 = ['a','b','c'];

var arr2 = ['d','e','f'];

  

var arr3 = arr1.concat(arr2);

console.log(arr3); // ['a','b','c','d','e','f']

console.log(arr1); // ['a','b','c'] —— 原数组没变！

  

var arr4 = arr2.concat(arr1); // 谁调用，谁在前

console.log(arr4); // ['d','e','f','a','b','c']

```

  

- **谁调用，谁在前**：`arr1.concat(arr2)` 是新数组把 `arr1` 放前面、`arr2` 接后面，反过来调用顺序就反转；

- 一次可以拼多个数组，全部按书写顺序接在后面；

- 返回全新数组，两个原数组都毫发无损——和七兄弟里的 `push` 一对比，气质完全不同。

  

# 三、toString：数组 → 逗号字符串

  

```js

var arr = [1,2,3,4,5,6,7];

console.log(arr.toString()); // "1,2,3,4,5,6,7"

// 元素之间用逗号连接，等价于 arr.join(',')

```

  

**数组被"当成字符串用"时，引擎会自动调用它：**

  

```js

alert(arr); // 弹窗显示 1,2,3,4,5,6,7

'数组是：' + arr; // "数组是：1,2,3,4,5,6,7"

```

  

> **冷知识：** `toString` 其实是所有对象都有的方法（来自 `Object.prototype`，第十三课讲过），数组对它**重新实现**了一遍——数组版的规则就是"用逗号把所有元素连起来"。所以 `alert(arr)`、`''+arr` 永远得到逗号连接的字符串。

  

**复习串联：** 先用 `splice(2,2,'f')` 把 `['a','b','c','d']` 改成 `['a','b','f']`，再 `toString()` 得到 `"a,b,f"`——改原数组的老方法 + 转字符串的新方法，配合无间。

  

# 四、slice 与 splice：一字之差，天壤之别

  

![slice 与 splice：一字之差，天壤之别](https://img.215454.xyz/file/blog/jia/1792058507210_03-slice-vs-splice.png)

  

```js

var arr = ['a','b','c','d','e','f'];

// -6 -5 -4 -3 -2 -1

  

var arr1 = arr.slice(-3,-1);

console.log(arr1); // ['d','e']

console.log(arr); // 原数组毫发无损

```

  

## slice 的三条规则

  

1. **区间 [start, end) 左闭右开**：`slice(1, 3)` 切出下标 1、2 两个元素，不含 3；

2. **负索引从尾部数**：`-1` 是最后一位，`slice(-3,-1)` 从倒数第三位切到倒数第二位之前；

3. **只传一个参数就一直切到末尾**：`slice(2)` 拿到下标 2 及其后面的全部元素。

  

## 全维度对比

  

| 对比项 | slice（切片） | splice（剪接） |

| :--- | :--- | :--- |

| 动原数组？ | **不改**，只读原数组切副本 | **改**，原地增删改 |

| 返回值 | 切出来的新数组 | 被剪掉的元素数组 |

| 参数 | `(start, end)` 左闭右开 | `(开始项, 剪切长度, 插入数据…)` |

| 一句话 | "复制切片" | "剪接修改" |

  

> **记忆口诀：** `slice` 只切不动刀，`splice` 动刀改原样。名字只差一个字母，行为天壤之别——面试最爱考的点之一。

  

# 五、join / split：数组与字符串的"任意门"

  

![join 与 split：数组与字符串的"任意门"](https://img.215454.xyz/file/blog/jia/1792058516294_04-join-split.png)

  

## 1. join：数组 → 字符串

  

```js

var arr = ['afdsf','bgafa','cfadfa','ddagad'];

var str1 = arr.join('-');

console.log(str1); // "afdsf-bgafa-cfadfa-ddagad"

  

var str2 = arr.join(); // 不传分隔符 = 用逗号连接，等同 toString()

```

  

分隔符想用什么就用什么：`join('-')`、`join('、')`、`join('')` 都行；同样不改原数组，返回的是全新字符串。

  

## 2. split：字符串 → 数组（反操作）

  

```js

var arr1 = str1.split('-', 3);

console.log(arr1); // ['afdsf','bgafa','cfadfa'] —— 限制个数：只留前 3 个

  

var arr2 = str1.split('-');

console.log(arr2); // ['afdsf','bgafa','cfadfa','ddagad'] —— 不限制，全部拆开

```

  

- **去的时候用什么分隔符，回来就得用什么分隔符拆**；

- 第二个参数可以**限制条数**；

- 空字符串分隔符能逐个掰开：`'abc'.split('') → ['a','b','c']`；

- `join` 和 `split` 互为逆操作：数组 ⇄ 字符串自由往返。

  

# 六、类数组对象：形似数组，却没有数组的魂

  

![类数组对象：形似数组，却没有数组的魂](https://img.215454.xyz/file/blog/jia/1792058518554_05-array-like.png)

  

## 1. 类数组长什么样

  

```js

var obj = {

'0': 1, '1': 2, '2': 3,

'length': 3

};

console.log(obj[1]); // 2 —— 取值没问题

console.log(obj.push); // undefined —— 没有 push！

```

  

**类数组三要素：**

1. 数字下标从 0 开始、连续递增；

2. 有 `length` 属性；

3. 原型直接是 `Object.prototype`。

  

所以它"形似数组，没有数组的魂"：用下标取值毫无问题，但 `push` / `slice` / `sort` 全都调不了。

  

## 2. 最经典的类数组：arguments

  

```js

function test(){

console.log(arguments);

// arguments.push(7); // 报错：没有这个方法

}

test(1,2,3,4,5,6);

// Arguments(6) [1, 2, 3, 4, 5, 6, …]

```

  

`arguments` 是类数组的活标本：函数内部自动生成、装满所有实参，有 `length`、有数字下标（`arguments[0]` 取值、for 循环遍历都行），但它**没有继承 Array.prototype**——想用数组方法得"借"。

  

> **一眼看穿真伪：** `console.log(obj.__proto__ === Array.prototype)` —— 输出 `false`，是类数组（或普通对象）；输出 `true`，才是真数组。真假数组的唯一分水岭就是原型链：长得再像，没接上 `Array.prototype` 就用不了数组方法。

  

# 七、借数组方法：经典 obj.push 覆盖题

  

![借数组方法：经典 obj.push 覆盖题](https://img.215454.xyz/file/blog/jia/1792058524495_06-array-like-push.png)

  

类数组没有数组方法，但可以"借"——把 `Array.prototype` 上的方法直接挂到对象自己身上：

  

```js

var obj = {

'2': 3,

'3': 4,

'length': 2,

'splice': Array.prototype.splice,

'push': Array.prototype.push

};

obj.push(1); // this[2] = 1，length 变 3

obj.push(2); // this[3] = 2，length 变 4

console.log(obj); // {2:1, 3:2, length:4, …}

```

  

## 逐步推演（经典笔试题）

  

`push` 的内心戏只有两步：**`this[this.length] = 元素`，然后 `length++`**。类数组有 length、有数字下标，"借"来就能用：

  

1. 初始 `{2:3, 3:4, length:2}`；

2. `obj.push(1)` 把 1 写进 `this[2]`（把原来的 3 顶掉），length 变 3；

3. `obj.push(2)` 把 2 写进 `this[3]`（把原来的 4 顶掉），length 变 4；

4. 最终 `{2:1, 3:2, length:4}`。**答案不是 3、4，而是 1、2！**

  

## 两种"借"法：挂原型 vs call

  

```js

// 演示：挂到 Object.prototype 上，全员可用

Object.prototype.push = Array.prototype.push;

var obj = { '0':1, '1':2, 'length':2 };

obj.push(3);

console.log(obj); // {0:1, 1:2, 2:3, length:3}

  

// 标准借用姿势：call 显式绑定 this（第十三课的显式绑定）

Array.prototype.push.call(obj, 4); // obj.length 变 4

```

  

> **警告：** 把方法挂到 `Object.prototype` 上，**全世界的对象**都能调 `push` —— 课堂实验玩一下可以，工程里千万别干（污染全局）。正经借法用 `call`：谁的方法、绑到谁的 `this` 上，清清楚楚。

  

# 本课小结

  

- **两大阵营**：七兄弟（push/unshift/pop/shift/reverse/splice/sort）改原数组；本课新朋友（concat/toString/slice/join）不改，返回新结果；

- **concat**：拼接生成新数组，"谁调用谁在前"，原数组毫发无损；

- **toString**：数组 → 逗号字符串（等价 `join(',')`）；被当成字符串用时引擎自动调用；

- **slice vs splice**：`slice` 左闭右开切副本、负索引、不改原数组；`splice` 原地增删改；"slice 只切不动刀，splice 动刀改原样"；

- **join / split**：互逆操作，`join(分隔符)` 拼、`split(分隔符, 限制个数)` 拆；`split` 是字符串的方法；

- **类数组三要素**：数字下标 + `length` + 原型是 `Object.prototype`；`arguments` 是活标本；

- **借用方法**：`obj.push` 覆盖题的关键是 `this[this.length] = 元素`；标准借法用 `Array.prototype.push.call(obj, x)`，别污染 `Object.prototype`。
